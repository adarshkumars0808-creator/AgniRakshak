CAPABILITIES

Built for real-time vigilance

From raw satellite pixels to verified, actionable fire-risk intelligence — the full pipeline runs automatically.

🛰️
Live Satellite Monitoring
Near-real-time NASA FIRMS thermal detections with 5-minute auto-refresh, severity classification, and pulsing live markers on the map.
🧠
ML Risk Scoring
Random-Forest risk model ranks 26,000+ grid cells 0–100 using recurrence, persistence, FRP intensity, and multi-satellite agreement.

ℹ️ About AgniRakshak
🎯 Project Overview

AgniRakshak is an AI-enabled geospatial system that automatically identifies, classifies, and monitors industrial fires and persistent thermal sources.


Data Sources:

  • NASA FIRMS — VIIRS SNPP, VIIRS NOAA-20, MODIS
  • ESA WorldCover — 10m land cover for site verification
  • OpenStreetMap — Industrial facility geolocation
🔬 Methodology
  • 5km FIRMS grid cells analyzed (2020–present)
  • ML-based risk scoring: FRP, recurrence, persistence, multi-satellite
  • Fire-type classification: Industrial, Agricultural, Forest/Wildfire
  • Land-cover verification via ESA WorldCover 10m
  • Regional zone aggregation for map display
